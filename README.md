# Тесты на проверку параметра параметра name при создании набора в Яндекс.Прилавок с помощью API Яндекс.Прилавок.
- Для запуска тестов должны быть установлены пакеты pytest и requests
- Запуск всех тестов выполняется командой pytest

## Содержимое проекта

- `configuration.py` — URL стенда и пути эндпоинтов.
- `data.py` — тела запросов и тестовые данные.
- `sender_stand_request.py` — функции отправки HTTP-запросов.
- `create_kit_name_kit_test.py` — тесты по чек-листу (11 проверок).
- `.gitignore` — игнорируемые файлы.
- `README.md` — этот файл.
